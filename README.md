# Технопрайм CRM · MELUWI

Демонстрация **сохранённого оригинального веб-интерфейса** CRM службы эвакуации. Дашборд, диспетчерская, формы, отчёты и кабинет водителя используют сборку рабочего проекта от 7 сентября 2026 года. Данные и API для демо подготовлены отдельно.

## Попробовать

Демо сразу открывает дашборд. Переключатель сверху открывает диспетчерскую или кабинет водителя. Учебный PIN: **1234**. Данные вымышлены, изменения сохраняются в этом браузере. «Сбросить» восстанавливает примеры.

- Создайте заказ во вкладке «Новая», выберите источник, тип заявки, водителя и тип техники.
- Откройте «Заявки»: доступны исходные карточки, фильтры, доплаты и способы оплаты.
- Сравните дашборд, отчёт смены и недельную сводку.
- Посмотрите график, парк, расходы, обслуживание и мобильный кабинет. Водитель «Альфа» имеет учебные задания.

Демонстрационный вход не является серверной аутентификацией. Не вводите реальные данные.

## Что находится в репозитории

`public/assets` содержит очищенный снимок оригинальной клиентской сборки, включая её стили и зависимости. Это скомпилированный JavaScript, **не восстановленные исходники TypeScript**. Оформление экранов не перерисовано заново.

`public/original/demo-api.js` — читаемый локальный эмулятор API: синтетические заказы, справочники, смены, расходы, записи ТО, расчёты, сохранение и сброс. `bootstrap.js` подключает его до запуска оригинального приложения. `index.html` изолирует окружение и запрещает внешние подключения политикой CSP.

`app/page.tsx` — небольшая оболочка с выбором роли, сбросом и WebMCP. `scripts/test-original-api.mjs` проверяет границы смен, распределение выручки по водителям, создание и завершение, восстановление удалённой заявки, расходы и сохранение.

## Границы демо

Оригинальный **интерфейс** сохранён. Производственный PHP/SQLite backend не запускается. Учебные API не воспроизводят все серверные проверки, тарифные исключения, документы и архивы. Телефония, реальные Telegram-сообщения, Avito, Яндекс, карты и push не подключены; демо сообщает об этом вместо отправки данных. APK и ключи подписи отсутствуют. Скриншоты мобильной версии показывают оригинальный адаптивный веб-интерфейс.

Обновления не синхронизируются между устройствами. При наступлении новой учебной смены примеры создаются заново. PIN публичный и предназначен только для демонстрации.

## Рабочий проект

CRM создавалась около полутора месяцев: диспетчерская, мобильные приложения диспетчера и водителя, учёт заказов, смен, денег, пробега, обслуживания и Telegram-событий. Рабочий стек: React, TypeScript, Zustand, Framer Motion, PHP, SQLite, Node.js/Express, WebSocket, Capacitor. Подробнее — в кейсе портфолио.

## Запуск

Node.js 22.13+.

```sh
npm ci
npm run dev -- --port 4174
npm test
npm run build
```

Выход статической сборки: `dist/client`. Конфигурация `.openai/hosting.json` относится к существующему экземпляру Sites; для собственного развёртывания используйте свой проект.

Исходные рабочие базы, fixtures, серверные конфигурации, аккаунты сотрудников, реальные номера и адреса в публичную сборку не включены. Сетевые адреса рабочего сервиса заменены, внешние каналы заблокированы. Локальный API не содержит токенов рабочего сервиса.
