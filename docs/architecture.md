# Устройство демонстрации

Оригинальная клиентская сборка React запускается внутри изолированного документа `/original/index.html`. Она сохраняет компоненты, верстку, формы, локальные расчёты и навигацию исходной CRM.

Перед её загрузкой `bootstrap.js` устанавливает локальный API. Запросы `/api/…` обрабатывает `createEngine`; запросы к внешним адресам отклоняются. CSP дополнительно запрещает внешние соединения, фреймы и worker. WebSocket и EventSource не подключаются к сети. Исходные интеграционные backend-модули отсутствуют.

## Данные

`demo-api.js` создаёт учебную неделю, четыре машины, четыре различных условных имени водителей, диспетчеров, заявки и расходы. Формат записей соответствует полям оригинального клиента: `status`, `pendingConfirm`, `deletedAt`, `equipmentLine`, `vehicleId`, `shiftDate`, `paymentMethod` и текст заявки с исходными метками полей.

Шаблон `report-shape.json` содержит только имена полей и пустые значения. В нём нет рабочих строк или идентификаторов. API заполняет шаблон расчётами из учебного состояния.

## Изменения

Создание возвращает `{ok, order}`; изменение сохраняет поля исходной формы. Предварительное завершение водителем ставит `pendingConfirm`, подтверждение диспетчером переводит заказ в завершённые. Удаление помечает `deletedAt`; восстановление возвращает запись. Завершённые активные записи участвуют в суммах отчёта. Расходы, график, ТО, партнёры и движения кассы хранятся отдельно.

Это эмуляция для осмотра продукта, не перенос полного backend. Некоторые серверные операции возвращают явное сообщение о недоступности в демо. Производственные тарифные исключения, ограничения ролей, выгрузки и интеграции требуют исходного backend и не заявляются как полностью воспроизведённые.

## Проверка

`npm test` проверяет финансовые итоги, разделение водителей, границу смены в Москве, создание, завершение, удаление/восстановление, localStorage, расходы, ТО и сброс. Интерфейс проверяется на учебных данных, без соединений с рабочей CRM.

WebMCP `get_demo_orders` возвращает доступные выбранной роли учебные заявки. `open_demo_dashboard` возвращает оболочку к исходному дашборду. Оба инструмента работают без серверного доступа.
